# Jenkins CI/CD Automation Pipeline

Hands-on continuous integration and continuous deployment engine utilizing declarative Jenkinsfiles. Covers containerized orchestration setups, multibranch pipeline management, secure credential handling, Git access tokens integration, stage filters, and iterative pipeline replay troubleshooting.

## Contents
- [setup.md](./setup.md) — complete setup guide detailing initial password generation, pipeline definitions, and GitHub repository integration
- [Jenkinsfile](./Jenkinsfile) — declarative automation script defining multi-stage pipeline controls, scoped environment variables, credential injections, and custom post-execution logic
